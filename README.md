# 🏨 Hotel Resource Allocation Engine

A simple **Hotel Management Web Application** built using **Spring MVC, JSP, and Apache Tomcat**.  
This project allows users to **add, view, and delete hotel rooms** through a clean and intuitive web interface.

## 📌 Project Overview

The **Hotel Management System** is a Java-based web application implemented using:

- Spring MVC (Controllers & routing)
- JSP & JSTL (UI rendering)
- In-Memory Repository (Room data storage)
- Apache Tomcat 11 (Jakarta EE 10 compatible)

### 🎯 Purpose of the Project
This project demonstrates understanding of:

- MVC Architecture  
- Servlet, JSP & Jakarta EE stack  
- Spring MVC controllers & dependency injection  
- WAR packaging and deployment on Tomcat  

---

## 🎯 Features

### 🛏️ Room Management
- Add new rooms with:
  - Room Number  
  - Room Type  
  - Price  
  - Availability  
- View all rooms  
- Delete rooms  

### 🧩 MVC Pattern
- **Model** → Room.java  
- **View** → rooms.jsp  
- **Controller** → RoomController.java
